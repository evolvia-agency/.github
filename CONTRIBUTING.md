# Contribuer aux dépôts Evolvia

- Branches : `feat/…`, `fix/…`, `chore/…` ; les agents IA travaillent sur `agent/<agent>/<mission>`.
- Commits conventionnels (`feat:`, `fix:`, `docs:`, `chore:`…), en français.
- PR obligatoire vers `main`, squash merge, CI verte et approbation d'un autre associé ; aucun push direct sur `main`.
- Aucun secret, aucune donnée client, aucune capture contenant des données personnelles.
